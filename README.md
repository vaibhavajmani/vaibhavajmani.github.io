## A note on the data

FlowBridge and the inventory integration use fictional company names. The problems,
constraints, and design patterns reflect real enterprise work. The Power BI report is
built on a public sample dataset; the data model, measures, design, and narrative are
my own. No employer data appears anywhere in this repository.

## Build

Static HTML, CSS, and vanilla JavaScript. No framework, no build step, no dependencies.
Hosted on GitHub Pages. Typography is Inter and IBM Plex Mono via Google Fonts.
`llms.txt` provides a plain-text summary for AI agents and crawlers.
